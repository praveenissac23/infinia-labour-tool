How to put it in
  1. Press Copy signature above (or select everything inside the white box and press Ctrl+C / Cmd+C).
  2. Outlook on PC: File → Options → Mail → Signatures → New → name it "Infinia" → paste (Ctrl+V) → set it for New messages and Replies/forwards → OK.
    Outlook on Mac: Outlook → Settings → Signatures → + → paste → choose it as the default for this account.
    Webmail (outlook.office.com): ⚙ Settings → Account → Signatures → + New signature → paste → Save → pick it under both defaults → Save.
  3. Delete any old signatures in that list so only this one is used.
  4. On a phone, clear the phone's own signature - Outlook app (Android/iPhone): Settings → Signature; Android Gmail: Settings → your email → Mobile signature; Samsung Email: Settings → your email → Signature off; iPhone Mail: Settings → Apps → Mail → Signature. The Infinia signature is added for you when you send.
